<Note>
**OmniRush.ai stays free when you use it locally.** Download the desktop app, connect your own model provider, and add custom MCP servers without signing in to OmniRush.ai Cloud. Sign in only when you want organization-managed providers, skills, connections, or policies. See [OmniRush.ai Cloud](/cloud/get-started) for those team features.
</Note>

Most people should start with the [OmniRush.ai app](https://github.com/omnirush-ai/omnirush-gui/releases/latest). It lets you use your own LLMs, skills, plugins, and MCP servers locally, then add Cloud when your team needs shared management.
